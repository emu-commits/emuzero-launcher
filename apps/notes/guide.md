# Markdown guide

Notes are plain text files. A few marks make them look better in View mode. You never have to use them: plain typing is fine.

View mode (what you see now) shows each mark working. This guide is read-only: **Alt → Duplicate to my notes** gives you a copy to try things in, and **Ctrl+E** there switches between View and Edit, so you can see the marks themselves.

## Headings

`# Big heading`
`## Smaller heading`
`### Smallest heading`

**Ctrl+H** in Edit mode steps a line through the three sizes and back.

## Bold, italic and more

`**bold**` gives **bold**
`*italic*` gives *italic*
`***both***` gives ***both***
`~~struck~~` gives ~~struck~~
`` `code` `` gives `code`

Select some words and press **Ctrl+B** or **Ctrl+I** to add or remove the marks.

## Checklists

`- [ ] oat milk` is an empty box:

- [ ] oat milk

`- [x] eggs` is a ticked one:

- [x] eggs

- **Ctrl+L** turns lines into items (and back).
- **Ctrl+Enter** ticks the item under the cursor. In View mode, **Space** does.
- **Enter** on an item starts the next one. Enter on an empty item ends the list.
- Typing `[] ` at the start of a line makes an item too.
- **Alt+Up / Alt+Down** (Alt+Fn+F / Alt+Fn+X) move a line.

## Lists

`- item` or `* item` makes a bullet:

- milk
- bread
  - indent with two spaces (or Tab)

`1. item` makes a numbered list:

1. first
2. second

Enter carries the list on, as with checklists.

## Quotes

`> quoted text` gives:

> Quoted text, set off with a bar.

## Links

`[the text](https://example.com)` shows the text, underlined:

[the text](https://example.com)

## A line across

`---` on a line of its own:

---

## Code

Three backticks on a line before and after:

```
the lines between keep
    their spaces, in a
monospace font
```

## Showing a mark as itself

Put `\` before it: `\*` shows \*not italic\*.

---

That's all of it. **Esc** goes back.
